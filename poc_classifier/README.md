# poc_classifier - intent-classifier proof of concept (NOT for production)
Branch: experiment/intent-classifier-poc (from DEV). Nothing here is imported by app/. No commits.

Files (created 2026-10-04):
- labels.py - 23-label space, definitions, pipeline-output -> label mapping, documented gaps (step 2)
- data/train.jsonl - 712 handwritten training rows, >=25 per label (step 3, frozen)
- data/test_matrix55.jsonl - the 55 matrix queries from run_matrix.py with gold labels (step 3, frozen; gold set BEFORE looking at pipeline output)
- data/test_golden.jsonl - 20 rows derived read-only from tests/golden_set.jsonl (step 3, frozen)
- data/test_fresh.jsonl - 59 new queries written after train.jsonl was frozen (step 3, frozen)
- data/HASHES.txt - SHA-256 of each data file at freeze time (test_fresh.jsonl was rewritten once, before any scoring, to drop 2 rows duplicating train; the earlier hash line is marked superseded)
- build_matrix55.py, build_train.py, build_golden.py, build_fresh.py - generators for the data files above
- leakage_check.py - exact + lowercased/whitespace-normalised overlap check vs matrix55 + golden_set
- freeze.py - appends data-file hashes to HASHES.txt
- results/_matrix_queries_raw.json, _extract_matrix.py - the 55 queries extracted from the old scratchpad run_matrix.py (verified: 55, #1 "find me a room", #55 "2bhk bangalore 15k 2bhk bangalore 15k")
- train.py, evaluate.py, artifacts/ - NOT written yet (steps 4-5 await label review)

Design notes: no prompt-injection strings are in train.jsonl on purpose, so the security check in step 5 measures a plain intent classifier.

CSV exports (generated by export_csv.py, 2026-10-04; JSONL stays the source of truth):
- data/train.csv - train.jsonl as CSV (text,label,has_room_context), 712 rows, same order
- data/test_matrix55.csv - test_matrix55.jsonl as CSV plus acceptable ("|"-joined) and score columns
- data/test_fresh.csv - test_fresh.jsonl as CSV plus acceptable and score columns
- data/test_newsearch_ctxY.csv - test_newsearch_ctxY.jsonl as CSV plus acceptable and score columns
- data/test_golden.csv - test_golden.jsonl as CSV (text,label,has_room_context)
